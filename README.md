# Best Recipes For You

Приложение с рецептами, дневником КБЖУ, планом на неделю и списком покупок. Работает как один HTML-файл, данные пользователя хранятся в `localStorage` браузера.

## Сборка

```bash
python3 build.py            # приложение-папка dist/ (страница, фото, иконки, PWA)
python3 build.py --single   # один файл dist-single/index.html со всем внутри
python3 build.py --watch    # пересобирать dist/ при каждом изменении
```

`dist/` выкладывается на хостинг с https целиком: тогда приложение можно установить на телефон
(«На экран Домой» / «Установить приложение») и оно работает без интернета.
`dist-single/index.html` открывается двойным кликом, но без установки и офлайна.
Иконки создаются скриптом `python3 tools/make_icons.py` (и `sips` на macOS для мелких размеров).

## Где что лежит

| Путь | Что внутри |
|---|---|
| `src/template.html` | оболочка страницы: head, шапка, навигация; метки `/*@CSS*/`, `//@DATA`, `//@JS` |
| `src/styles.css` | стили |
| `src/app.js` | код приложения (читает всё из объекта `DATA`) |
| `data/recipes.json` | рецепты: категория, КБЖУ, время, кухня, ингредиенты `[строка, продукт, граммы]` |
| `data/food.json` | продукты: `[ккал, белки, жиры, углеводы]` на 100 г |
| `data/subs.json`, `data/ratio.json` | замены продуктов и коэффициенты пересчёта граммов |
| `data/allerg.json`, `veglevel.json`, `shopcat.json` | аллергены, уровень вегетарианства, отделы для списка покупок |
| `data/presets.json` | готовые планы питания |
| `data/langs/<код>.json` | переводы интерфейса, рецептов и продуктов (ru, en, uk, kk, ka, es, de, fr) |
| `data/photos/<id>.webp` | фото блюд, имя файла = id рецепта; источники в `CREDITS.md` |
| `data/icons/` | иконки приложения |
| `data/portion.json` | вес одной штуки для местных блюд (хинкали, манты…) |

Порядок языков и ключей `DATA` задан в начале `build.py`. Новый язык подхватится автоматически, если положить файл в `data/langs/`.
